# Слот-машина (Лабораторная работа №10)

**Описание:** Приложение-слот-машина на Flutter с поддержкой звука. Демонстрирует работу с аудиофокусом, жизненным циклом приложения, генерацию иконок и сборку под Web и Android.

## Стек и версии

- Flutter 3.0+
- Dart 3.0+
- Пакеты: `audioplayers: 6.8.1`, `flutter_launcher_icons: 0.14.4`

## Как запустить

1. Клонировать репозиторий: `git clone https://github.com/ALISAKonovalova/Flutter_Lab10.git`
2. Перейти в папку: `cd Flutter_Lab10`
3. Установить зависимости: `flutter pub get`
4. Запустить: `flutter run -d chrome`

## Что изучили

1. Подключение звука в Flutter (Web и Android).
2. Управление аудиофокусом и жизненным циклом.
3. Генерация иконок с помощью `flutter_launcher_icons`.
4. Сборка Web-версии.
5. Подготовка к сборке APK.
